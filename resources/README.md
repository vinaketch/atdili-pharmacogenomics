# External resources

This directory documents external resources used during the
pharmacogenomic analysis.

The actual genomic databases and allele-definition files are not
stored in this repository unless their redistribution is permitted.

## StellarPGx

StellarPGx resources were used for pharmacogene allele and diplotype
assignment.

Repository:
https://github.com/SBIMB/StellarPGx

## PharmVar

PharmVar was used to review pharmacogene allele definitions and to
investigate potentially novel or unresolved alleles.

## Allele-definition files

Gene-specific allele-definition VCF files were obtained from the
StellarPGx resources and matched to the corresponding pharmacogene.

The specific database/resource versions used in the analysis are
documented in `docs/software_versions.txt`.
